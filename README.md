# WPS 报告计时器

一个用于 WPS 演示的 Windows 报告计时工具。通过 WPS 内置的“工具”页签启动，使用完全透明的悬浮窗显示倒计时，进入幻灯片放映后自动开始，超时后从 `-0:00` 继续负数计时。

## 功能

- 合并到 WPS 演示内置“工具”页签，不创建单独的插件页签
- 透明紧凑悬浮窗，只显示时间数字和右上角关闭按钮
- 自动检测 WPS 放映窗口，无需修改 PPT 或启用宏
- 放映时自动定位到放映屏幕右上角
- 默认 10 分钟，可自定义分钟和秒数
- 归零后显示红色 `-0:00`、`-0:01`……
- 退出放映后自动回到等待状态
- 支持拖动、暂停、继续和重新计时
- 单实例运行，重复点击不会打开多个计时器

## 安装

### 下载安装包

进入本仓库的 **Releases** 页面，下载最新版安装包并解压。

### 安装加载项

1. 双击 `Install_WPS_Addin.bat`。
2. 完全退出并重新打开 WPS 演示。
3. 打开一个 PPT，在“视图”旁的内置 **工具** 页签末尾点击 **启动报告计时器**。

首次调用本地程序时，WPS 可能显示安全提示，请允许本插件启动计时器。

也可以直接运行 `启动计时器.bat`，不通过 WPS 功能区启动。

## 使用

- **设置时长**：等待放映时双击时间数字，或用鼠标滚轮按分钟调整。
- **开始计时**：启动工具后，在 WPS 中进入幻灯片放映即自动开始。
- **超时提醒**：时间到零后，数字变红并显示负数超时时间。
- **移动位置**：拖动时间数字；开始放映时会移动到放映屏幕右上角。
- **暂停或重置**：右键时间数字，选择相应操作。
- **退出**：单击数字右上角的 `×`。
- **测试效果**：运行 `测试超时效果.bat`，打开 5 秒演示。

## 卸载

双击 `Uninstall_WPS_Addin.bat`，然后重启 WPS。卸载脚本只移除本项目，不影响其他 WPS 加载项。

## 环境要求

- Windows 10/11
- 桌面版 WPS 演示，支持 JavaScript 加载项和 `OAAssist.ShellExecute`
- 系统自带 .NET Framework 4.x

## 项目结构

```text
WpsReportTimer_1.0.1/   WPS 加载项及已编译的计时器
src/                    C# 源码与计时逻辑测试
install.ps1             加载项安装脚本
uninstall.ps1           加载项卸载脚本
build.ps1               编译与测试脚本
```

## 从源码构建

在 Windows 上运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

脚本使用系统自带的 .NET Framework C# 编译器，重新生成 `WpsReportTimer_1.0.1/WpsReportTimer.exe` 并运行计时边界测试。

## 隐私与文件安全

本工具只读取 WPS 的放映窗口状态，不修改 PPT 文件，不收集或上传演示内容。安装脚本在修改 `publish.xml` 前会创建备份，并保留其他加载项条目。
